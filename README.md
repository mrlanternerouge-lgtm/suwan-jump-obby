# Suwan Jump Obby

A small Roblox obby with 15 progressively smaller platforms, three red hurdles, a lava floor, checkpoints at stages 4, 8 and 12, and a Goal celebration HUD.

## Open and play

Open `Suwan Jump Obby.rbxlx` in Roblox Studio and press Play. Use the normal Roblox movement and jump controls. Green platforms are checkpoints; red surfaces kill the character. Progress lasts for the current server session and resets on rejoining.

The place includes the complete map and exactly two game scripts. `ObbyServer.luau` and `ObbyHUD.luau` are matching source exports; editing an export does not automatically update the place. Copy edits into the corresponding Studio script before republishing.
